# 西安交通大学思源学堂课件下载器

一个用于西安交通大学思源学堂 (LMS) 系统的课件下载脚本，支持批量下载课程课件资源。

## 功能特性

- 📚 **批量下载**：一键获取课程所有课件下载链接
- 📁 **多附件支持**：支持每个课件项下的多个附件
- 🔓 **无权限课件**：可获取未提供直接下载按钮的课件链接
- 📋 **链接复制**：支持复制所有下载链接到剪贴板
- 🎨 **友好界面**：清晰的层级结构显示，操作简单直观
- ⚡ **稳定可靠**：完善的错误处理和重试机制

## 安装方法

### 前置要求

1. 安装浏览器扩展：[Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)
2. 支持的浏览器：Chrome、Firefox、Edge、Safari

### 安装步骤

1. 打开浏览器扩展管理页面
2. 创建新脚本
3. 将 `xjtu-lms-courseware-downloader.user.js` 文件内容复制粘贴到编辑器
4. 保存脚本 (Ctrl+S)

## 使用说明

1. 登录西安交通大学思源学堂：https://lms.xjtu.edu.cn
2. 进入任意课程的"课件"页面
3. 点击页面右下角的红色按钮 **"📥 获取课件下载链接"**
4. 等待脚本自动获取所有课件信息
5. 在弹出的面板中选择下载方式：
   - **单个下载**：点击每个文件旁的下载按钮
   - **本组下载**：点击课件项的"下载本组"按钮
   - **下载全部**：点击底部的"下载全部"按钮
   - **复制链接**：点击"复制链接"将所有下载链接复制到剪贴板
