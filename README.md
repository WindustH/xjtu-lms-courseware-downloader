一个用于西安交通大学思源学堂 (LMS) 系统的课件下载脚本，支持批量下载课程课件资源。

## 功能特性

- 📚 **批量下载**：一键获取课程所有课件下载链接
- 📁 **多附件支持**：支持每个课件项下的多个附件
- 🔓 **无权限课件**：可获取未提供直接下载按钮的课件链接
- 📋 **链接复制**：支持复制所有下载链接到剪贴板
- 🎨 **友好界面**：清晰的层级结构显示，操作简单直观
- ⚡ **稳定可靠**：完善的错误处理和重试机制

## 安装方法

### 前置要求

1. 安装浏览器扩展：[Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)
2. 支持的浏览器：Chrome、Firefox、Edge、Safari

### 安装步骤

1. 打开浏览器扩展管理页面
2. 创建新脚本
3. 将 `xjtu-lms-courseware-downloader.user.js` 文件内容复制粘贴到编辑器
4. 保存脚本 (Ctrl+S)

## 使用说明

1. 登录西安交通大学思源学堂：https://lms.xjtu.edu.cn
2. 进入任意课程的"课件"页面
3. 点击页面右下角的红色按钮 **"📥 获取课件下载链接"**
4. 等待脚本自动获取所有课件信息
5. 在弹出的面板中选择下载方式：
   - **单个下载**：点击每个文件旁的下载按钮
   - **本组下载**：点击课件项的"下载本组"按钮
   - **下载全部**：点击底部的"下载全部"按钮
   - **复制链接**：点击"复制链接"将所有下载链接复制到剪贴板

## 界面说明

### 文件标识

- 📖 **章节信息**：显示课件所属的章节/单元
- 📦 **文件大小**：显示附件的文件大小
- 📄 **文件名**：显示附件的完整文件名
- ⬇ **下载按钮**：绿色按钮表示可下载
- ❌ **无法获取**：红色图标表示无法获取下载链接

### 特殊标签

- **无版权警告**：橙色标签，表示该课件未提供官方下载按钮，通过技术手段获取

### 统计信息

面板顶部显示：
- 课程号
- 课件项数量
- 文件总数
- 可下载文件数量

## 技术说明

### 工作原理

1. **课件信息提取**：遍历页面中的所有课件项，获取课件基本信息
2. **附件展开**：自动展开每个课件项的附件列表
3. **下载链接获取**：通过访问 `/api/uploads/{uploadId}/blob` 接口获取重定向后的实际下载地址
4. **Angular数据读取**：从页面的 Angular.js scope 中读取课件和附件的元数据

### 支持的文件类型

- PowerPoint 演示文稿
- Word 文档
- 视频文件 (MP4等)
- 压缩包 (ZIP等)
- 其他附件类型

## 常见问题

### Q: 为什么有些课件无法下载？

A: 可能的原因：
- 课件附件已被删除
- 网络连接问题
- 服务器权限限制

### Q: 下载的文件名乱码怎么办？

A: 脚本已包含文件名清理功能，如仍有问题请手动重命名。

### Q: 可以下载其他学校的课件吗？

A: 本脚本专为西安交通大学思源学堂设计，不保证在其他平台可用。

### Q: 使用脚本会被封号吗？

A: 本脚本仅模拟正常用户操作，不会对服务器造成异常请求。但请合理使用，避免频繁操作。

## 故障排除

### 脚本无法运行

1. 确认 Tampermonkey/ userscript 扩展已启用
2. 确认脚本已正确安装并启用
3. 刷新页面后重试

### 无法获取下载链接

1. 确认已登录思源学堂
2. 检查网络连接
3. 等待页面完全加载后再点击获取按钮

### 浏览器阻止下载

1. 检查浏览器的下载设置
2. 允许 `lms.xjtu.edu.cn` 和 `media.xjtu.edu.cn` 的下载权限
3. 检查是否安装了广告拦截插件
